PARAM SHAKTI – HPC ACCESS AND WORKFLOWS

This directory contains documentation, scripts, and resources related to accessing and using the PARAM Shakti Supercomputing Facility at IIT Kharagpur.

Directory Structure

test_scripts/ – Basic test programs and environment verification.

pytorch_submission/ – PyTorch GPU execution scripts and experiments.

slurm_scripts/ – SLURM job submission scripts.

logs/ – Job output and error logs.

PARAM_SHAKTI_USER_MANUAL.pdf – PARAM Shakti user manual.

Purpose

To maintain organized documentation and practical resources for HPC access, GPU computing, and job submission workflows.
