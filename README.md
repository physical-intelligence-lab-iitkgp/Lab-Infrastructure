# Lab-Infrastructure

Research infrastructure documentation, HPC workflows, and computational experiments at Physical Intelligence Lab IIT Kharagpur.

# Cluster Access

Documentation, sanity checks, PyTorch test submission code, and Slurm job templates for running jobs on the compute cluster.

## Get Started

1. SSH into the cluster login node: `ssh <username>@<cluster-login-host>`
2. Navigate to scratch and clone the repository: `cd $SCRATCH && git clone https://github.com/physical-intelligence-lab-iitkgp/Lab-Infrastructure.git`
3. Enter the cluster documentation directory and run the environment check: `cd Lab-Infrastructure/cluster_access && bash test_scripts/test_env.sh`
4. Activate your configured Python/PyTorch environment and submit the test job: `sbatch slurm_scripts/submit_pytorch.slurm`
5. Monitor the job using `squeue -u $USER` and inspect the output in `logs/pytorch-smoke-test-<jobid>.out`.

## Folder Structure

- `test_scripts/test_env.sh`: Checks host, user, directory, Slurm availability, GPU/CUDA status, and PyTorch setup.
- `pytorch_submission/test_pytorch.py`: Runs a short PyTorch training smoke test on GPU (or CPU fallback) and reports timing/memory.
- `slurm_scripts/submit_pytorch.slurm`: Slurm batch script for submitting the PyTorch test.
- `logs/`: Stores `.out` and `.err` log files generated by Slurm jobs.
- `PARAM_SHAKTI_USER_MANUAL.pdf`: Reference manual for the cluster.

## Cluster Notes

- PARAM Shakti uses Slurm for job scheduling.
- The GPU partition is named `gpu`.
- GPU jobs should request GPUs through Slurm.
- Use `$SCRATCH` for research/project files and job submissions.
- Scratch data is temporary and is not backed up; maintain local copies of important files.
- Login nodes are for editing, file transfer, environment setup, and job submission—not for running compute-intensive workloads.
- Update the SSH login hostname and environment activation commands to match the actual cluster configuration.
